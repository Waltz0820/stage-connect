# Stage Connect V2 — 共通UI・トップ（Gate 1）

2026-10-23。写真に依存しない編集デザインへ、共通ヘッダー／フッターと日英トップを変更する。ユーザーはラフ踏襲・既存システム維持・本番反映を承認済み。

## 実装

- 巨大な `STAGE / CONNECT`、短いH1、検索、既存DBの登録件数。
- 俳優・作品・シリーズの3色導線。
- 既存4シリーズの順序を維持した文字の棚。スマホは大1→小2→大1、PCは4列。
- 既存10項目の推しポイント検索。IDとクエリは変更しない。
- `getGuideList()` の公開済み記事だけを掲載。英語トップでは日本語記事へのリンクであることを明示。
- DMM導線のURLと `home_banner` 計測属性を保持し、ガイドの後へ移動。
- スマホ初期は巨大ロゴ、スクロール後は固定ヘッダーの小ロゴ。下層では小ロゴを初期表示。
- 既存検索APIを使う検索ダイアログ。IME送信抑止、候補、0件、通信失敗、Esc、背景スクロール抑止、フォーカス管理。
- メニュー・フッターの既存ナビと言語切替を維持。Aboutはまだ公開していないためリンクを追加しない。
- 登場アニメーションは一度だけ。JS不動作・reduced-motionでも本文とリンクは表示。ヒーロー検索は非JS時に既存検索ページへ遷移する。

## ラフとの差分

- 正式なシリーズ名・登録件数・公開ガイドは実データ。ラフのダミー値や架空記事を使わない。
- アイコンは既存SVGを再利用し、試作の代用記号に置き換えない。
- 検索／メニューの操作領域は44pxを確保。
- 既存DMM導線を削除せず、新しいトップ下部にフラットなリンクとして配置。
- 英語版未公開のガイド記事は翻訳済みと見せず、日本語記事であることを明示。
- 共通シェルは下層にも適用するが、下層本文・配信ページ固有のテーマは今回変更しない。

## 検証

- `tsc --noEmit --incremental false`：成功。
- 本番ビルド `npm run build`：成功（Next.js 15.5.28）。
- 検索・日英切替・配役・配信・投票の既存テスト38件：成功。
- 本番用ローカルサーバーで既存60ページ：成功。
- 検索APIの11パターン：成功。
- トップ・俳優・作品・シリーズ・配信・プライバシー・ガイドの9ページについて、変更前のtitle/description/canonical/hreflang/JSON-LDを照合。
- トップ以外の7ページは本文と本文内リンクも照合。
- 320/390/430/768/1024/1440pxの日英トップ：横溢れなし、検索が初期画面内に表示。
- スクロール後の小ロゴ、実検索候補、検索・メニューのTab循環／Esc／フォーカス復帰／スクロールロック解除、0件からの回遊、検索結果への遷移、reduced-motion、非JS：検証済み。最終操作テストでブラウザエラー0件。

ブラウザ検証では外部広告／解析ネットワークの読込をテスト環境だけで分離。アプリ本体と実検索APIは実通信で検査する。GA・広告・成果認定の外部システムそのものの検査ではない。

開発サーバーの並行コンパイルで一度発生した500は、本番ビルド＋`next start`へ切り替えて再検査。ローカルに残っていた古いfetchキャッシュも退避し、既存データ更新による件数差とUI変更を分けて確認した。

スクリーンショット・変更前スナップショット・ブラウザ検査結果はGit外の `stageconnect-v2-design/` に保存。iPhone Safari実機、ソフトキーボード、端末復帰時の操作は未検証。
