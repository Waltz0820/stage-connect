# 詳細一覧ダイアログのiPhone向け修正

シリーズ詳細の全キャスト表示について、iPhoneで開けないとの報告を受けた修正。

- 旧 `.section-card > *` の位置指定とブラウザ任せのモーダル配置が混在していたため、共通ダイアログを `position: fixed; inset: 0; margin: auto` で画面内に配置。`vh` のフォールバックと内部スクロールを明示。
- iOSでフォーカス移動時に背景の位置が変わるのを避けるため、開く前にbodyを固定し、閉じた際は元のスタイルとスクロール位置を復元。
- 全キャストのデータ・人数・順位・役名・URLは変更しない。共演者の一覧にも同じ修正を適用。

本番ビルド成功。WebKitとChromeのiPhone相当のタッチ環境で、JP/ENのテニミュ全キャストと俳優の共演者一覧について、長いページの下からの表示、画面内への収まり、末尾までのスクロール、閉じる、元位置の復元、再度開く操作を検証（6組×2回）。実物のiPhone上での再現確認ではない。

変更ファイル：`next-app/components/DetailDialog.tsx`、`next-app/app/editorial-details.css`。DB・API・環境変数の変更なし。
