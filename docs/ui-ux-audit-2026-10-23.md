# UI・UX監査と配信ページの刷新

## 方針

メリハリのあるフラットデザイン、短く応答する動き、作品・俳優・シリーズの回遊を優先。説明や同じ数値の繰り返しで補わず、文字の大きさ・色面・余白・操作範囲で関係を示す。既存データの事実監査やDB更新は対象外。

## 監査して維持した部分

- トップのテクスチャーと文字組み、青・コーラル・ライムの探索バナー。
- Aboutの強めの演出。通常ページの触覚的な反応との強弱。
- 俳優・役柄・共演者・シリーズ・公演年表の実リンク。
- OSの「視差効果を減らす」への対応、JSなしでも読めるHTML。
- キャストダイアログのフォーカス管理、iOSでの背景固定・スクロール復元。

## 修正

| 観察 | 対応 |
| --- | --- |
| 一覧冒頭の件数と説明が結果件数を繰り返す | 冒頭をカテゴリと見出しに絞る。件数は結果の直前に一度表示 |
| 俳優1件にイニシャル・名前・補足の複数リンク。同じ行の余白が押せない | 行全体を一つの実リンクに統合。キーボードも1件1停止 |
| 作品・シリーズのカードに「詳細を見る」が反復 | カード全体を実リンクにして矢印で示す。作品名や分類は保持 |
| モバイルの条件選択を閉じると適用状態が見えない | 適用数バッジと解除可能な条件チップ。1条件だけ解除して検索語・他条件を維持 |
| 検索結果0件で復帰先が弱い | 全3一覧に条件クリアの出口を用意 |
| シリーズ冒頭の作品数・種別が二重に表示 | ピルを除去し、数値欄に集約 |
| シリーズのカードにも形式・原作区分が二重に表示 | 属性行に集約。ガイドの汎用的な説明チップ、検索・お気に入りの重複説明も整理 |
| 年表で全幅の黒い配信ボタンが作品名より目立つ | リンクと計測を保ったまま控えめな外部リンクボタンへ |
| 横長の詳細目次で現在の項目が画面外に出る | スクロール中の現在地に合わせて目次内だけを横移動。本文の位置は変えない |
| 無効な前・次リンクがキーボードで選択できる | aria-disabledとTab順を整備 |
| ナビの現在地が色にしか出ない | PC・モバイルにaria-currentを付与 |

## 配信ページ

`/watch`とDMM TV・U-NEXT・dアニメストアの各ページをJP/ENで刷新。

- ライムのヒーローと太いタイポグラフィ。装飾は写真を使わない舞台の図形。
- 作品検索とサービス選択をファーストビューに配置。既存GET条件とIME対応を使用。
- 一覧は料金・無料体験・サービスへの入口を揃えて比較可能に。細かな条件はネイティブdetailsで開く。
- 個別ページは作品への入口を先に、料金・条件はその後に配置。見放題・配信中との断定はしない。
- 作品リンクはタイトル主体の一覧。各サービスの公式カタログへの出口を維持。
- DMMプレミアムの登録リンクは条件確認の後に配置。広告表示と既存URL・rel・計測属性を保持。
- FAQと公式参照先は開閉式。FAQ本文・構造化データ・料金条件・確認日は既存値を保持。
- 登場・開閉・押下・矢印の短い動きを追加。OSのモーション軽減時は停止。

## 検証

検証記録は作業領域の `stageconnect-v2-design/ux-*` に保存。公開ページの既存データは書き換えず、表示・導線の回帰確認として比較する。

- Next.js本番ビルド・TypeScript。
- 既存の配信URL・計測・検索・言語切替の単体テスト。
- JP/ENの62ルート確認。
- 変更前本番と29ページのSEO・構造化データ・主要本文・配役・年表・外部リンクを比較。
- Chrome/WebKit、320/390/768/1440pxの表示、カード・フィルター・メニュー・目次・戻る・FAQ操作。
- JavaScript無効時の検索・条件選択・開閉操作。
- 外部サービスへのテストクリックや本番の投票書き込みは行わない。

実機iPhoneの検証ではなくWebKitのモバイルエミュレーションを使用。

一括スクリーンショット検証は80レイアウトと12操作群の表示・動作を確認。高速でURLを直接切り替えるWebKit実行では中断されたNext.js先読みのエラーが記録されたため、実リンク・検索・戻る操作を使った連続回遊を別コンテキストで再確認。Chrome/WebKitとも連続回遊時のページエラーは0件。元の診断ログも保持する。

最終確認では各ページを独立したブラウザコンテキストで開き、30ケースの表示・検索結果0件からの復帰を確認（ページエラー0件）。最後の文言整理後もJP/ENシリーズ一覧・ガイド・お気に入り・検索を390/1440pxで撮影し、はみ出しなし。2026-10-24に最終の本番ビルドが正常終了。
