## 配役の手書き補足

`cast-credit.mjs` は原文を保持し、役名、グループ、世代、チーム、公演地、出演条件、日付の補足を読み取り用の構造に分ける。
実DBへの移行や公開画面への置き換えは行っていない。

| 既存表記 | 解釈案 |
| --- | --- |
| 福岡公演※日替わりゲスト | 公演地「福岡」と日替わりゲスト条件 |
| 鶴丸国永※声 | 役名「鶴丸国永」と声の出演 |
| 役A / 役B | 複数役の候補を保持 |
| 豊前江※犬山道節・浜路 | 補足を要確認として原文保存。追加の役名か出演形態かを推測で確定しない |

一人の役数と、声・映像・舞台上などの出演形態は別の情報として扱う。
中黒は人名・役名の一部にもなるため、機械的な役の区切りにしない。
「※以降を消す」処理は公開側に残っており、今回の読み取り処理には使っていない。

2,140配役中345行に補足を検出し、うち10行を未知の補足として抽出した。
テニミュ1stは238行、刀ステは35行、刀ミュは65行に補足がある。
認識できた文言も、意味を資料で全件確認した状態ではない。未知10行だけを調べれば移行できるとは判断しない。
同じ俳優・作品の条件を含めた比較キーでは重複候補は出なかった。

## 取り込みの照合修正

`source-match.mjs` を既存の `import-kira-hai.mjs` へ組み込んだ。

- 衝突時に最初の1件を選ばず、複数候補として保留する。
- 再演・公演中止・延期などの文字をタイトル照合で消さない。長音符「ー」も残す。
- 読み・ローマ字URLだけの一致で人物を確定しない。旧芸名は明示された別名を使って照合する。
- 年が明示的に食い違う公演を候補から除く。
- `limit(10000)` の1回読みをページ取得に変更し、サーバーの返却上限による取りこぼしを避ける。

実例はキラハイの「村上耕平」と既存の「村上幸平」。同じ `murakami-kohei` というURL表記から同一人物としない。
「土屋裕一」と「土屋佑壱」も、別名の根拠がない照合段階では要確認に残す。
この修正を用いた広範囲の候補DB再取り込みは実行していない。既存の手動照合を再実行時に保全する処理も、本格運用前の課題に残る。

## 作品単位の情報抽出

`kira-hai-work.mjs` と `inspect-kira-work.mjs` で、個別作品の日程・キャスト欄を取得し、保存済み俳優に照合する。
リンクのない人名、アンサンブル、バックダンサーも原文の区分を保って抽出する。SNS共有欄やコメントを出演者へ混ぜない。
未知の行がある場合は不完全な一覧を確定扱いせず停止する。
実際にアクセスした個別作品はrobots.txtの拒否パスに該当しないことも確認した。

### 加州清光 単騎出陣 アジアツアー：登録までの試行

対象は既存の刀ミュシリーズの2019年ソロ公演。

- [第一参照先・キラハイ](https://kira-hai.net/nelketoukenkashu2019)
- [公式公演情報](https://musical-toukenranbu.jp/pages/kashusololive_asia)
- [公式英語告知](https://musical-toukenranbu.jp/contents/213998)

佐藤流司＝加州清光、バックダンサー6名、上海・バンコク・マカオ・日本凱旋の日程を照合した。
役付き1名は既存 `casts`、ダンサー6名は既存 `plays.credits` に一致するため、出演者を重複追加しなかった。

空欄だった `title_en` と `summary_en` だけを追加した。
英語タイトルは公式告知の表記を参考にし、紹介文は出演者・日程の確認できた事実に限定した。
日本語の宣伝的な評価を含む紹介文の逐語訳ではない。

`apply-reviewed-play-patch.mjs` は確認済みのJSON計画を読み、既定では差分確認のみ。
`--apply` 指定時も、ID・slug・確認時の更新日時・対象カラムのnull条件が一致した場合だけ1行更新する。
更新前と送信予定をローカルへ保存してから反映し、再取得して対象外の項目を検証する。
同じ内容の再実行は `already_applied` で終了することを実DBで確認した。

根拠と変更内容を既存 `external_import_logs` に1件登録した。
更新とログは別のRESTリクエストであり、単一トランザクションではない。
通信途絶時は作業ディレクトリの `write_pending` とDBを突き合わせる必要がある。
