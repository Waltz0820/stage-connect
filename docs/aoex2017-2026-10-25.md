# 舞台「青の祓魔師」島根イルミナティ篇とシリーズ点検

対象：[2017年作品](https://stageconnect.jp/plays/aoex2017) / [シリーズ](https://stageconnect.jp/series/ao-no-exorcist) / [英語シリーズ](https://stageconnect.jp/en/series/ao-no-exorcist)

## 保存・検証

- 初回試行は人物出典URLの一意制約で停止。複数人共通の公演ページを人物キーに使わず、人物ごとの放送局・人物紹介URLへ修正した。次の試行はシリーズ更新結果のJSON式の演算順で停止し、個別SELECTで原因を確認して括弧を修正。どちらも本番反映前のトランザクションで全体が戻り、制約を緩めていない。
- 修正後、ロールバック付きSQLを実行し、新作品・バッチ履歴0件、総数とシリーズ英題が元に戻ることを確認して本番適用した。
- 全8テーブル比較で人物6・作品1・配役14・候補14・人物出典6・履歴38件を追加。既存更新は対象シリーズの上記項目のみ。既存全人物・作品・配役・出典・候補・履歴を保全し、削除なし。
- 同じSQLを本番で再実行し、全8テーブルの追加・更新・削除0件を確認した。
- 採用根拠と原文・例外は`next-app/research/aoex2017-20261025.json`へ保存。網羅性ファイルは青の祓魔師のみ更新。DBスキーマ・RLS・アプリコードの変更と再デプロイは不要。
- 全体は俳優1,085人・作品389件・配役3,787件・シリーズ198件。
