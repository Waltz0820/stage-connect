# 公開画面の残存UI整理

トップの舞台ヒーローに合わせ、作品情報は白・ネイビー・藤色へ整理する。

## 変更

- JP/ENの作品・シリーズ一覧、作品詳細、関連作品から疑似ポスターを撤去。共通のProductionMarkで小さな装飾アイコンを表示する。
- 刀剣乱舞・テニミュの既知のシリーズは刀・ラケット、公演形式が分かる一覧は舞台・音符、その他は作品・シリーズの汎用アイコンを使う。分類データは追加しない。
- 一覧・詳細の背景から仮の舞台風イラストを撤去。モバイル詳細ではアイコンと作品名、その下にシリーズ・操作・基本情報を表示する。
- ガイド内の暗いカード、配信比較の強いピンク、お気に入りの四角いタブを公開画面の配色へ統一。デスクトップのフッターをコンパクトにする。
- お気に入りの切り替えボタンにaria-pressedを追加。

## 確認・公開記録

本番ビルドと34ページの表示・SEO・導線チェック成功。JP/ENと390px/1280pxの実画面で横方向のはみ出しがないことを確認。作品詳細の配役・公演情報・配信・投票への目次、お気に入りの切り替えも確認済み。

DB変更・マイグレーションなし。投票API、作品データ、料金・配信の説明文、アフィリエイトのリンク先は変更しない。
