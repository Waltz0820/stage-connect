# 舞台『K』2014年初演の補完

対象：[2014年初演](https://stageconnect.jp/plays/k-stage-first) / [シリーズ](https://stageconnect.jp/series/k)

役付き出演14人を公演公式とキラハイで照合。既存5配役を再利用し、役名の空欄4件を埋め、9配役と5人物を追加する。アンサンブル8人は役名・兼役も含めて作品クレジットへ収録。

## 判断と保全範囲

- 初演公式は主要11人と、別行の十束多々良・椎名敦士、雪染菊理・山内優花、三科草太・松本祐一を掲載。別行という理由で3役を落とさず計14役を収録。
- 既存の松田凌・荒牧慶彦・植田圭輔・鈴木拡樹の役名空欄を公式に基づいて補完。中村誠治郎の周防尊と合わせ、既存5配役のID・作成日時・補足・出演区分・主演指定を保持し、掲載順を公式順に設定する。旧主演指定の妥当性は別途監査。
- 公式アンサンブルは校條拳太朗・日南田顕久・滝川広大・田中涼星・緒方陽太・由月杏奈・江口千夏・藤本貴行の8人。キラハイにある秋山氷杜、弁財酉次郎／出羽将臣、加茂劉芳、道明寺アンディの役名を最初の4人の氏名へ添えて残す。役名があるだけで主要配役へ昇格させず、既存俳優の削除も行わない。
- 2014年8月6日〜10日、六本木ブルーシアター。公式ページのtitleに曜日の誤記があるが、本文日程と別の公式作品ページ、第一参照先で日付が一致。曜日は転記しない。
- 中村の旧採用候補には別作品の文章が混入。原文・採用情報と誤年2021を履歴として保全し、今回の正常な周防尊候補を別に作って既存配役へ接続する。旧候補の履歴整理は別工程。
- 作品ID・slug・正式タイトル・会場・ジャンル・タグ・配信設定を保持。`vod`のDMM/U-NEXTの`#`は既存の仮リンクで、視聴可否を今回確認済みとは扱わない。
- 原作、脚本・演出、アンサンブルの3区分を補完。作品の日英概要・英題、シリーズの短い客観説明と英語名・概要を整える。詳細スタッフの推測転記は行わない。
