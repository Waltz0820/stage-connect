# シリーズ完了時の点検

2026-10-20、ユーザー確認。大きな誤りを公開したまま次の大量登録へ進めないため、1シリーズの登録を一区切りにして、点検と必要な修正を挟む。

## 毎回確認するもの

1. 第一参照先と公演公式に対する作品の抜け、対象ジャンル、正式タイトル、別シリーズとの混同、重複。
2. 公演年・全開催地の日程／会場、同年内の開始日、年表の表示年と並び順。
3. 通常役・兼役・声／映像・日替わり出演と、公式アンサンブル／ダンサー／演奏の保存先。別枠に掲載されているだけで役付き出演を除外しない。
4. 人物の旧名／改名・同姓同名・既存人物との重複。未確認の生年・読み・所属等を埋めるために推測しない。
5. 日英のタイトル・説明・残る未翻訳、配役カード、クレジット、作品／俳優／シリーズの相互リンク。掲載済みの翻訳と保護対象データは維持する。

出典で直せる大きな誤りはその場で修正する。根拠が足りないもの、あらすじ・プロフィール・詳細の全英訳、配信確認、掲載順や主演指定等は理由と範囲を残す。点検済みを全項目の翻訳・総合監査が完了した意味にしない。

DB変更では変更前を保存し、対象と変更項目を絞り、可能なら同一トランザクションで試行・適用する。主要テーブルを比較し、再実行の重複や対象外の変更がないこと、日英の公開表示を確認する。採用記録・シリーズ収録状況・点検メモを更新して次のシリーズへ進む。

細かな人物情報の総合監査は後続へ回せるが、作品・公演・人物の取り違え、配役漏れ、架空の基本情報、表示上の大きな誤年は保留せず優先して扱う。アンサンブルと子役は[収録方針](ensemble-credit-policy.md)に従って個別判断する。
