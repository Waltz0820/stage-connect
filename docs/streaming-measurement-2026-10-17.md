# 年表・配信導線・クリック計測の修正

2026-10-17。既存データは読み取りのみ。DBマイグレーションなし。

## 年表の空欄

シリーズ詳細の旧CSSが登録済みの作品概要を `display:none` にしていた。日英とも専用の `timeline-excerpt` で2行まで表示する。概要が空の作品には抜粋要素を作らない。

併せて、年表の「作品詳細を見る」が白地に白文字になっていたCSSの優先順位を修正。主ボタンは藤色背景・白文字に統一した。作品概要そのものの追記や生成は行っていない。

確認時点でテニミュ1st 23作品・刀ミュ43作品・刀ステ20作品には全件概要があった。テニミュ2ndの9作品は概要未登録なので、空欄を埋める作文はせずタイトル・日付・作品詳細ボタンを表示する。

## 配信リンクの判定

`next-app/lib/streaming-links.ts` で取得時にVOD情報を正規化する。空文字・空白・`#`・不正なURL・サービスと異なるドメインのURLはリンクとして扱わない。DMMのアフィリエイトURLとパラメータは保持する。DBの元データは変更しない。

確認時点の実HTTPリンクはDMM55作品。U-NEXT25作品・dアニメ3作品の欄はすべて空文字か `#` だった。これらを「配信あり」とする誤判定を解消した。「未確認」は配信されていないという意味ではない。既存リンクの現在の販売・配信期間、見放題／レンタル区分までは保証せず、リンク先で確認できる案内を付ける。

現在は公式ドメインとDMMの既存 `al.dmm.com` 形式を扱う。将来U-NEXT等の別アフィリエイト事業者のURLを追加するときは、確認済みの転送形式を判定に追加する。今回、価格比較記事や各サービスの最新ラインナップを監査したわけではない。

## GA4のクリック計測

イベント名は `streaming_click`。内部の配信ガイドへの遷移と外部配信サイトへのクリックを区別する。登録・購入・売上・CVRを表すイベントではない。リンクの表示回数は今回の計測対象外。

| イベントパラメータ | GA4表示名 | 内容 |
| --- | --- | --- |
| streaming_service | 配信サービス | dmm / unext / danime / all |
| placement | 配信リンクの表示位置 | 下記の表示位置 |
| link_kind | 配信リンクの種類 | guide / outbound |
| site_locale | サイト表示言語 | ja / en |
| page_type | ページ種別 | home / plays / series / actors / guide / watch など |
| play_id | 対象作品ID | 対応する作品の固定UUID。作品リンクがある場合のみ |
| play_slug | 対象作品スラッグ | 対応する作品のURL識別子。作品リンクがある場合のみ |

表示位置: `header`, `mobile_menu`, `footer`, `home_banner`, `play_hero`, `play_streaming`, `actor_timeline`, `series_timeline`, `guide_play`, `guide_content`, `watch_hero`, `watch_content`。

`page_path` と `page_location` も送るが、追加イベントの値には検索クエリやアフィリエイト先の生URLを入れない。作品IDは公開作品の識別子であり利用者IDではない。クリックはcapture段階で観測し、Next.jsの内部遷移やモバイルメニューの閉鎖前にリンク文脈を取得する。リンク遷移を止めたり送信完了まで待たせたりしない。左クリック・中クリック・キーボード操作に対応し、アンマウント時にリスナーを解除する。

GAタグの初期化は公開本番ホストに限定。localhost・Vercelプレビュー・管理画面では初期化しない。GA初期化のキューを先に用意してからページビューとクリックを送る。SPA内のページビューはアプリ側で送信する。

### 管理画面で実施済み

Stage Connectプロパティ `516745984`、Webストリーム `13154997017`、測定ID `G-KLT69885CC` で確認。

- 上記7項目をイベントスコープのカスタムディメンションとして登録。画面上の7件の保存とGSC WizardのGA4 Admin APIによる7件の取得で確認。

設定前の確定済みデータ（2026-09-16～2026-10-13）ではpage_view 1,113件、一般的なclick 14件。過去のclickに新しい作品・表示位置の項目を後から補うことはできない。

カスタムディメンションが通常レポートで利用可能になるまで時間差がある。実ユーザーの新イベント受信と定常レポートの蓄積は公開後に確認する。GA4とDMM管理画面では遮断・計測方法・集計対象が異なるため、クリック件数の一致は前提にしない。

参考: [GA4のページビュー計測](https://developers.google.com/analytics/devguides/collection/ga4/views)、[拡張計測](https://support.google.com/analytics/answer/9216061)、[イベントスコープのカスタムディメンション](https://support.google.com/analytics/answer/14240153)。
