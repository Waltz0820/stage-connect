# 複数会場・都市数の表示修正

2026-10-21。DIVE!!の東京・大阪が「1会場」と表示されていた件を修正。会場データは両方とも保存されており、日英作品詳細が` / `だけをリストの区切りと解釈していたことが原因だった。

## 変更

`next-app/lib/performance-list.ts`へ表示用の共通処理を追加し、半角スラッシュ前後の空白・全角スラッシュ・改行を解釈するようにした。日付の`2018/9/20`や`２０１８／９／２０`と、会場名内部の`A/B`は分割しない。DBの文字列は書き換えない。

都市名は半角／全角コロンと日本語日付、直接記載の都市名＋日付を扱い、同じ都市を重複して数えない。都市ラベルのない日付や開演時刻から都市を作らない。日本語側で未対応だった全角コロンも処理する。英語は同じ都市一覧を既存の翻訳処理へ渡す。

日英ともサーバー側の純粋な文字列処理で、DBクエリ・クライアントJS・新規依存は増やしていない。Reactスキルのチェックでサーバー／クライアント境界・追加I/O・レンダリングへの影響も確認した。文字は既存のReactテキスト描画を使い、HTMLとして解釈しない。
